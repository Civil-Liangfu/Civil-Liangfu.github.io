Research · Theme 02

Structural Damage Detection

Finding damage early by combining load and response measurements with machine learning, influence lines, and acoustic signals.

Damage, such as cracks or a loss of stiffness, changes how a structure responds to load. The challenge is to detect these small changes in real monitoring data, where traffic, temperature and noise also change the response all the time.

This research develops damage detection methods that use both the input (the load acting on the structure) and the output (how the structure responds), together with machine learning.

Main contributions

  • Vision-based influence lines with weigh-in-motion: detecting bridge damage from precise displacement influence lines measured by cameras, with vehicle loads from weigh-in-motion devices, validated by experiments (Ge et al., 2023).
  • Input–output monitoring with transfer learning for structural damage detection (Ge et al., 2024).
  • Domain adaptation for bridge health monitoring, using physics-informed generative adversarial learning (Ge & Sadhu, 2024).
  • Automated crack identification from acoustic waveforms with deep learning (Barbosh et al., 2024).
