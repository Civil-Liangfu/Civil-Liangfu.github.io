Visual inspection is still the main way bridges are checked. But it is slow and costly,
and it can be dangerous, especially for parts that are hard to reach or under water. This
research uses robots and deep learning to make inspection more automatic.

## Main contributions

- **Smart ground robot:** a deep-learning-enhanced ground robotic system that inspects
  structures for damage and maps it automatically {% cite ge2025deep %}.
- **Underwater detection with sonar:** an advanced deep learning framework for detecting
  underwater objects with multibeam forward-looking sonar {% cite ge2025advanced %}.
- **Drone-based underwater detection** for structural health monitoring
  {% cite ge2024drone %}.
